# BACKEND WITH NODE


## 1- PASO

### UBICARSE EN LA RUTA DE LA TERMINAL DEL PROYECTO BACKEND
$ cd Backend

## 2-PASO

### ARCHIVO .env DENTRO DEL PROYECTO

### AGREGAR LAS VARIABLES DE ENTORNO

### DB_HOST=localhost
### DB_PORT=5432
### DB_USER=postgres
### DB_PASSWORD=postgres
### DB_DATABASE=db_crud
### PORT=3002

## 3- PASO

### USAR EN TERMINAL EL SIGUIENTE COMANDO PARA EJECUTAR EL PROYECTO

$ docker compose up
